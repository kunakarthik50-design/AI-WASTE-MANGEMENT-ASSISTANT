🌿 EcoSort AI: Intelligent Waste Management & Resource Conservation Assistant

EcoSort AI is a full-stack, AI-driven waste management, recycling, and resource conservation web platform. Built with Python, Flask, PyTorch Deep Learning Computer Vision, and SQLite, it empowers households, institutions, and communities to classify waste with pinpoint accuracy, eliminate recycling contamination, locate certified recycling hubs, and actively reduce their direct water and carbon footprints.

🌟 Key Capabilities

1. 🔍 Multi-Modal AI Waste Classifier

  • Deep Learning Vision Engine: Leverages a pre-trained PyTorch MobileNetV2 deep neural network mapped to a comprehensive waste taxonomy (Plastics, Paper & Cardboard, Glass, Metals & Aluminum, Organics & Compost, E-Waste, Hazardous Chemicals, Textiles, and Residual Landfill).
  • Live Webcam & Drag-and-Drop Image Capture: Snap direct photos via your browser's webcam or drop image files (JPG, PNG, WEBP) onto the interactive dropzone.
  • Natural Language Item Search: Search over 100+ household materials by text with fuzzy keyword matching.
  • Granular Classification Output:
    • Item identification & confidence metric
    • Recommended disposal destination with standardized bin color coding
    • Step-by-step preparation guidelines (rinsing, cap removal, film separation)
    • Estimated natural decomposition duration (e.g., Plastic bottle: 450 years vs. Apple core: 2-5 weeks)
    • Quantified environmental diversion benefits: Liters of water saved and kg of CO2 emissions prevented.
  • Optional Gemini Vision Integration: Toggle high-detail multimodal LLM analysis via GEMINI_API_KEY environment variable.

2. 💧 Water & Resource Conservation Hub

  • Interactive Daily Water Footprint Calculator:
    • Dynamically calculates direct indoor consumption across showers, low-flow fixture aerators, faucet habits during hygiene, toilet flush volume, dishwashing methods, and laundry loads.
    • Computes personal environmental ratings and reveals annual savings potential (often 20,000+ liters/year).
    • Factored diet virtual water benchmark integration.
  • Actionable Resource Conservation Guides:
    • Quantified step-by-step practices across Water Conservation, Composting 101, Single-Use Plastic Elimination, and Energy Efficiency.

3. 📍 Recycling Facilities & E-Waste Locator

Searchable and filterable database of municipal clean streams, certified electronic recyclers, composting hubs, hazardous chemical depots, and textile reclamation banks. Detailed listings with accepted materials badges, operating schedules, phone numbers, and direct GPS mapping links.

4. 🏆 Interactive Eco-Master Quiz

Interactive challenges covering common recycling myths, circular materials, compost dos and don'ts, and global water conservation facts. Instant explanations with certified Eco-Master badge rewards.

5. 📊 Eco-Impact & Waste Audit Tracker

Comprehensive personal dashboard calculating:

  • Total items scanned
  • Landfill diversion efficiency rate (%)
  • Cumulative water preserved (L) & CO2 emissions prevented (kg)
  • Material distribution breakdown across streams
  • Complete historical log with status updater (Logged → Recycled / Composted / Disposed) and audit management.

🚀 Getting Started

1. Prerequisites

  • Python 3.10+ (Fully tested on Python 3.14)
  • Pip package manager

2. Installation

  1. Clone or navigate to the repository directory: 
    cd "d:/IPE Project"
  2. Install required dependencies: 
    pip install -r requirements.txt

    (For CPU PyTorch: pip install torch torchvision --index-url https://download.pytorch.org/whl/cpu)

  3. Initialize the database and pre-seed default facilities and guides: 
    python -c "from app import seed_database; seed_database()"

    (Optional) Insert sample scans for demonstration:

    python seed_samples.py

3. Running the Application

Launch the local development server:

python app.py

Open your browser and navigate to:

http://localhost:5000

🧪 Running Unit Tests

Execute the automated test suite verifying database models, classification logic, water calculations, and REST endpoints:

python test_app.py

📡 REST API Reference

POST /api/classify

Classifies a discarded item via image upload, webcam frame, or search query.

  • Request (Multipart/Form-Data or JSON):
    • image: Image file (optional)
    • webcam_data: Base64 JPEG data URI (optional)
    • query: Text string (optional, e.g., "aluminum can")
  • Response (JSON): 
    {
  "success": true,
  "item_name": "PET Plastic Beverage Bottle",
  "category_name": "Recyclable Plastic",
  "category_key": "plastic",
  "confidence": 0.94,
  "bin_color": "Yellow Recycling Bin",
  "prep_instructions": "Rinse thoroughly, remove bottle cap, flatten.",
  "decomposition_time": "450 years",
  "water_saved_liters": 3.5,
  "co2_saved_kg": 0.15,
  "scan_id": 1
}

POST /api/calculate-water

Computes direct daily water consumption and savings potential.

Request (JSON):

{
  "shower_minutes": 8,
  "showerhead_type": "standard",
  "teeth_tap_running": false,
  "toilet_flushes": 5,
  "toilet_type": "dual_flush",
  "dishwashing_method": "dishwasher",
  "laundry_loads_week": 3,
  "diet_type": "balanced"
}

POST /api/scan/<int:scan_id>/status

Updates recycling disposition status for a logged scan (Recycled, Composted, Disposed).
